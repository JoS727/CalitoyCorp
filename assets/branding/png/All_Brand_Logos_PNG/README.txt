All Brand Logos PNG Package
============================

This package contains transparent PNG exports rendered from the reconstructed SVG logo set.
Folders are organized by brand, then Brand_Color and One_Color.

Export spec:
- Transparent background
- Longest side rendered to 4000 px
- File names match the SVG package

Source note:
These PNGs were generated from the previously reconstructed SVG vectors, not original master artwork.
